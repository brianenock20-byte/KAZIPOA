09 / deployment strategy
A controlled path from soft launch to public scale.
The current stack is full-stack and managed: React, Express/tRPC, MySQL, authentication, storage, notifications, and automatic checkpoint publishing.
01 / PLATFORM
Managed full stack
Manus hosting runs the application, server, database, auth, storage, and release checkpoints as one operational surface.
02 / DOMAIN
Bind the final origin
Connect `portol.kazipoa.co.tz`, verify DNS and HTTPS, and align APP_BASE_URL, canonical URLs, robots, and sitemap.
03 / DISCOVER
Open the SEO loop
Submit the final sitemap, inspect representative vacancy URLs, and validate JobPosting rich results in Search Console.
04 / OPERATE
Launch with evidence
Run controlled seeker, employer, and Admin tests, then monitor uptime, payments, alerts, indexing, and Core Web Vitals.
