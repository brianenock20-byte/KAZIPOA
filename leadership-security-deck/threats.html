03 · RISK ASSESSMENT

Threat model priorities

Highest-impact attack paths identified during the design phase and the mandatory controls required for production release.

Attack Path Impact Required Control
Admin Procedure Abuse
Non-admin calling privileged APIs		 CRITICAL Server-side adminProcedure middleware; deny-by-default tests; generic 403 responses.
Privilege Escalation
Changing roles via guessed IDs		 CRITICAL Role checks + target ownership/org scope; transactional last-admin protection; audit logging.
Data Leakage in Exports
Secrets or PII in CSV/XLSX		 HIGH Explicit output allow-lists; cell escaping for formula injection; secret field exclusion.
Session/Auth Forgery
Replaying or forging callbacks		 CRITICAL Nonce/state binding; secure cookie flags; rate limits; session re-evaluation on block.
!

Release Blockers

Any Admin procedure callable by non-admins, cross-tenant data access, or ability to remove the last active Admin will block production deployment.
